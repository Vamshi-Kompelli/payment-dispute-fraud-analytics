# Payment Dispute & Fraud Analytics

Portfolio project using **synthetic data only** to analyze payment transactions, debit disputes, fraud indicators, operational queues, merchant risk, and resolution performance.

## Deliverables
- PostgreSQL schema, load script, indexes, and analysis queries
- Four synthetic CSV datasets and a formatted Excel/Power BI source workbook
- Star-schema guidance, DAX measures, and a four-page dashboard specification
- Business questions and interview walkthrough

## Repository structure
`data/` synthetic source data; `sql/` database scripts; `powerbi/` model, DAX and dashboard specification; `docs/` portfolio narrative.

## Important
This repository is a guided portfolio asset. Rebuild the SQL queries and Power BI report yourself, keep the synthetic-data disclosure, and be prepared to explain every measure and design choice. Do not represent the dashboard as completed until you create and publish the `.pbix` file.
